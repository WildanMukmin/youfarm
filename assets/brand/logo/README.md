# Logo

Konsep terpilih: **Y + Play**. Huruf Y dengan segitiga play di celahnya (video lahir dari satu ide). Sudut tajam, selaras dengan brand dark crimson.

| File | Pakai untuk |
|---|---|
| `youfarm-mark.svg` | Ikon utama dalam kotak gelap bergaris crimson (sidebar, ikon aplikasi) |
| `youfarm-glyph.svg` | Huruf Y + play saja, tanpa kotak, untuk di atas latar gelap |
| `youfarm-mark-mono.svg` | Satu warna putih, untuk watermark atau overlay video |
| `youfarm-wordmark.svg` | Ikon + teks "YouFarm" |
| `../../icons/app/icon.ico` | Ikon aplikasi Windows (256, 128, 64, 48, 32, 16 px) |
| `../../icons/app/icon.png` | PNG 256 px untuk jendela Electron |
| `archive/` | Tiga konsep lain yang tidak dipilih, disimpan sebagai arsip |

Catatan:
- Teks di `youfarm-wordmark.svg` sudah berupa outline (Chakra Petch 700), tidak bergantung font. Dibuat ulang bila teks berubah.
- Ruang kosong minimum: setengah lebar ikon di semua sisi. Jangan diberi bayangan atau diubah warnanya.
- `.ico` dan `.png` diturunkan dari `youfarm-mark.svg`. Bila SVG berubah, buat ulang keduanya.
